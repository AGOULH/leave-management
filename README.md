# موقع المجموعة السعودية لعلم الدم المناعي (SIG)

موقع ثابت ثنائي اللغة (عربي/إنجليزي) يعمل مجاناً على **GitHub Pages**، مع **Firebase** (الخطة المجانية) للحسابات والبيانات.

## الصفحات
| الملف | الوصف |
|---|---|
| `index.html` | الرئيسية: شريط أخبار، الفعالية القادمة مع عدّ تنازلي، الخدمات، الأرشيف |
| `about.html` | الرسالة والرؤية والأهداف، المؤسس، المجالس، الفريق، مجموعات الاهتمام |
| `events.html` | الفعاليات القادمة + تسجيل مجاني بتذكرة QR + تقديم ملخص + الأرشيف |
| `library.html` | المكتبة العلمية (بحث وتصفية) ومعرض الصور |
| `membership.html` | إنشاء عضوية مجانية |
| `contact.html` | نموذج تواصل موجّه للأقسام + أسئلة شائعة |
| `portal.html` | بوابة العضو: البطاقة الرقمية، التسجيلات، الشهادات، الملخصات، الملف |
| `admin.html` | لوحة التحكم: الفعالية، التسجيلات، الحضور بالمسح، الشهادات، الملخصات، الأعضاء، الأخبار، الرسائل |
| `card.html` / `certificate.html` | طباعة البطاقة والشهادة (PDF من المتصفح) |

## الوضع التجريبي
إذا كانت إعدادات `firebase` في `assets/js/config.js` فارغة يعمل الموقع **بوضع تجريبي**: كل شيء يعمل لكن البيانات تُحفظ في متصفحك فقط، ولوحة التحكم مفتوحة.

## ربط Firebase (مرة واحدة — مجاني)
1. أنشئ مشروعاً **جديداً مستقلاً** في https://console.firebase.google.com (حتى لا يتشارك حدود Spark مع مشاريعك الأخرى).
2. **Authentication › Sign-in method** › فعّل **Email/Password**.
3. **Authentication › Settings › Authorized domains** › أضف `agoulh.github.io` (ونطاق المجموعة إن رُبط لاحقاً).
4. **Firestore Database** › Create database (Production mode، منطقة قريبة مثل `me-central2` أو `europe-west`).
5. **Firestore › Rules** › الصق محتوى `firestore.rules` ثم **Publish**.
6. **Project settings › Your apps › Web (</>)** › انسخ قيم `firebaseConfig` إلى `assets/js/config.js`.
7. ارفع التعديل (git push).

### جعل حسابك مشرفاً
1. أنشئ حسابك من صفحة **العضوية** في الموقع.
2. من **Authentication › Users** انسخ الـ **UID** الخاص بك.
3. في **Firestore** أنشئ مجموعة `admins` ثم مستنداً **معرّفه = UID** (أي حقل، مثل `name: "Hasan"`).
4. ادخل `admin.html` — ستظهر لوحة التحكم.

## تعديلات شائعة
- **الفعالية القادمة** (العنوان، التاريخ، المكان، الساعات، فتح/إغلاق التسجيل): من لوحة التحكم › «الفعالية والمواعيد».
- **روابط مواد الفعاليات السابقة**: `materials` في `config.js` (مفتاح كل فعالية موجود في `SIG.ARCHIVE` داخل `assets/js/common.js`).
- **الصور**: ضعها في `assets/img/gallery/` وأضف مساراتها في `gallery` داخل `config.js`.
- **البريد الرسمي وحسابات التواصل**: `contactEmail` و `social` في `config.js`.
- **النصوص الثابتة**: في ملفات HTML — النص العربي داخل العنصر والإنجليزي في `data-en`.

## ملاحظات
- لا يستخدم الموقع Firebase Storage (يحتاج خطة مدفوعة)؛ الملفات تُرفع كروابط Google Drive أو داخل المستودع.
- الشهادات والبطاقات تُحفظ PDF من نافذة الطباعة في المتصفح.
- النسخة السابقة من المستودع (تطبيق الإجازات) محفوظة في الفرع `backup-leave-app`.
